===========================================================
  HƯỚNG DẪN THÊM NHẠC NỀN CHO TRANG WEB (THƯ MỤC /audio)
===========================================================

1. CÁCH THÊM BÀI HÁT TẶNG MẸ:
   - Copy file nhạc định dạng .mp3 (hoặc .m4a, .aac, .ogg) vào thư mục này.
   - Đặt tên file là: `nhac-tang-me.mp3`
   - Hoặc bạn có thể đặt tên bất kỳ rồi mở file `config.json` ở thư mục gốc để sửa đường dẫn tại:
     "audio": {
       "enabled": true,
       "src": "audio/ten-file-nhac-cua-ban.mp3",
       "title": "Giai điệu tặng Mẹ"
     }

2. GỢI Ý MỘT SỐ BÀI HÁT Ý NGHĨA VỀ MẸ:
   - Nhật Ký Của Mẹ (Hiền Thục)
   - Mẹ Yêu (Phương Uyên / Ba Con Mèo)
   - Ước Mơ Của Mẹ (Văn Mai Hương)
   - Con Yêu Mẹ (Bảo Thy)
   - Nhạc hòa tấu piano / guitar nhẹ nhàng không lời (rất êm dịu và cảm xúc)

3. CƠ CHẾ HOẠT ĐỘNG:
   - Các trình duyệt trên điện thoại (Safari iPhone, Chrome Android) luôn chặn nhạc tự động phát có âm thanh để tránh làm phiền người dùng.
   - Do đó, trang web được thiết kế một nút "Bật nhạc 🎵" trang nhã ở góc trên màn hình. Mẹ có thể bấm vào bất kỳ lúc nào để thưởng thức.
   - NẾU BẠN CHƯA BỎ FILE NHẠC VÀO: Nút nhạc sẽ tự động ẩn đi, không gây lỗi giao diện.
